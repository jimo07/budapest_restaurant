# 测试与验收

## 自动检查

在仓库根目录运行：

```bash
pnpm test
```

该命令执行后端测试、所有 TypeScript 类型检查和两个前端的生产构建。

当前后端领域测试覆盖 35 个场景，包括价格精度、订单状态、顾客取消、配送/自取/堂食履约、库存、时段容量、支付约束、角色权限和查询令牌。GitHub Actions 会在每次推送及 Pull Request 时自动执行同一套检查。

## 发布前人工验收

1. 三种语言切换后，无需刷新，导航、表单、菜名、状态、错误提示和打印内容保持同一语言。
2. 午餐和晚餐可分别选菜，库存与时段容量正确扣减。
3. 配送、自取、堂食订单分别进入对应工作清单，堂食排位不出现其他订单。
4. 商家确认后触发小票打印；顾客在制作前可取消，制作后不可自行取消。
5. 订单显示与履约方式匹配的履约码，堂食显示桌号，取消单不显示履约码。
6. 现金订单可以显著地确认收款，未支付完成订单会进入提醒。
7. 普通员工无法使用超出角色范围的后台功能。
8. 手机端必填项错误提示滚动到可见位置，购物车和订单入口具有明确图标。
