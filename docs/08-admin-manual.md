# 商家后台操作手册

## 日常处理顺序

1. 登录后台并选择营业日。
2. 在待处理订单中确认订单；确认后系统进入打印流程。
3. 开始备餐时将订单推进到制作中，此后顾客不能自行取消。
4. 完成备餐后标记已备好，并按取餐码、配送码或就餐码核对履约。
5. 现金订单在实际收到款项后点击确认收款。

## 业务清单

- 自取清单只显示自取单。
- 配送清单只显示配送单。
- 堂食清单和排位只显示堂食单，并展示桌号与人数。

## 配置维护

- 菜单管理：维护菜品三语名称、描述、分类、价格和上下架状态。
- 菜单库存：按营业日和餐段设置可售数量，售罄后顾客端停止加购。
- 餐段与容量：分别维护午餐、晚餐和三种履约方式的时段容量。
- 员工账号：按岗位授予权限；禁用账号后应立即禁止登录。
- 审计日志：用于追踪关键配置、订单和账号操作。
