# 需求与范围

## 当前产品范围

- 顾客端：三语菜单、午晚餐切换、购物车、配送/自取/堂食预约、现金/线上支付方式选择、订单查询与取消。
- 商家端：订单处理、收款、打印、菜单与库存、餐段容量、配送区域、桌位、账号权限、审计日志和经营设置。
- 服务端：公开下单接口、后台鉴权与权限控制、订单状态流转、履约码、库存和容量校验。

## 核心规则

- 商家开始制作前，顾客可以取消订单；进入制作后需联系餐厅处理。
- 配送、自取、堂食清单和排位必须分开统计。
- 有效订单使用取餐码、配送码或就餐码；堂食订单同时展示桌号。
- 金额以 HUF 存储和展示，界面遵循匈牙利数字格式。
- 界面支持中文、英语和匈牙利语即时切换；业务数据需要保存三语字段。

## 暂缓范围

- 正式线上支付通道。
- Google Maps 正式 API Key 和计费账号接入。
- 正式云环境、域名、HTTPS、监控和自动备份。
- 最终品牌 Logo、餐厅和菜品图片。
