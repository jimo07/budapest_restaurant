# API 概览

API 位于 `apps/server`，本地默认地址为 `http://127.0.0.1:8000`。

接口按用途分为：

- 公开接口：菜单、餐段、时段容量、配送区域、桌位、创建和查询订单。
- 顾客订单接口：凭查询凭证查看详情、取消符合条件的订单。
- 后台接口：登录、订单处理、收款、打印、菜单库存、经营规则、管理员和审计日志。

统一响应结构由 `packages/api-types` 维护。后台接口必须携带登录令牌，并由服务端执行角色权限校验，不能只依赖页面隐藏按钮。

具体路由和本地调试方式见 `apps/server/README.md` 与 `apps/server/route`。
