# 部署说明

当前阶段以本地联调和临时商家验收为主，正式生产部署尚未启用。

## 临时测试

先在根目录运行 `pnpm dev`，再按需要使用安全隧道发布。测试结束后关闭隧道进程，即可撤销公共访问。不要公开默认管理员账号，也不要把 `.env`、数据库密码或 API Key 上传到仓库。

## 正式上线前需要完成

- 选择欧洲区域服务器、托管数据库和对象存储。
- 配置正式域名、HTTPS、反向代理和进程守护。
- 设置生产环境变量、Google Maps Key 和支付服务商密钥。
- 开启数据库与上传文件备份、错误监控、访问日志和告警。
- 创建最小权限管理员账号，删除或禁用所有演示账号与演示数据。

正式基础设施配置后续放入 `deploy/`，与本地业务代码分离。
