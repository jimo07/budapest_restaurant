# Budapest Restaurant Admin

布达佩斯餐厅订单预约管理后台，基于 Vue 3、TypeScript、Pinia 和 Vite。

## 首版功能

- 管理员登录和登录状态保存
- 响应式侧栏与移动端导航
- 营业日数据概览、订单状态及履约分布
- 热销商品与预约时段容量
- 订单筛选、详情、状态推进和管理员取消
- 订单分页、多选和批量状态推进
- 配送、自取、堂食履约状态操作
- 堂食桌台分配和预约时段调整
- 确认收款、登记退款与订单打印
- 厨房、配送、自取、堂食作业看板
- 分类、商品、餐次、时段、配送区域和桌台配置列表
- 六类基础配置的新建、编辑与软停用
- 套餐组成商品与数量编辑
- 餐次菜单、售价、库存和上下架配置

## 本地运行

先启动后端：

```bash
cd ../server
php think run
```

再启动后台：

```bash
pnpm install
pnpm dev
```

开发环境会将 `/api` 代理到 `http://127.0.0.1:8000`。本地演示账号为 `admin / Admin@123456`。

## 检查

```bash
pnpm build
pnpm lint
```
